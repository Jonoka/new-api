# 充值余额与订阅套餐用途提示

## 变更目标

在充值操作区明确区分充值余额与订阅套餐，避免用户误以为充值后的余额可用于购买订阅套餐。

## 变更范围

- Classic 充值页在额度充值内容顶部展示用途提示。
- Default 钱包页在充值卡片顶部展示同等提示。
- 提示文案支持两套前端现有的全部界面语言。

## 页面文案

- 充值余额仅用于 API 调用消耗，不可用于购买订阅套餐。
- 订阅套餐请在「订阅套餐」页面单独购买。

本次仅完善充值页文案，不修改充值、订阅购买、支付、结算或权限逻辑。

## 安全与兼容性

- 不展示账户、订单或支付敏感信息。
- 不新增接口、配置、数据结构或数据库迁移。
- 保持现有充值与订阅功能行为不变。

## 已知限制

- 当前代码仍保留“余额购买订阅”配置；部署方应确保产品配置与本提示一致。
- 当前普通用户套餐购买组件仍嵌在充值页，独立的 `/subscriptions` 路由是管理员套餐管理页。本次文案调整不负责拆分普通用户购买页面。

## 验证计划

1. 检查 Classic 与 Default 充值区域均展示两行提示。
2. 检查各语言翻译键完整且 JSON 格式有效。
3. 执行 Default 前端类型检查与相关代码格式检查。
4. 执行 `git diff --check`，确认没有空白符错误。

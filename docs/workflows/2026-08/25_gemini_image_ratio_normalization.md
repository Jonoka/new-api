# Gemini 图片尺寸比例归一化修复记录

日期：2026-08-25

## 问题

无限画布选择 `3:4` 时，前端发送的像素尺寸为 `864x1152`，`nano-banana-v2`
请求最终生成了 `1024x1024`。

## 根因

Gemini 图片适配器原先只识别少数历史 DALL-E 尺寸。`864x1152` 未命中后回退为
`aspectRatio: "1:1"`，Native Gemini 因此按方形生成。

## 修改范围

- Gemini Native 预览/编辑路径对 `WxH` 尺寸使用最大公约数归一化，再匹配
  Nano Banana 2 已验证的比例集合；`864x1152` 转为 `3:4`；
- 未知尺寸或不支持比例继续回退 `1:1`；
- Imagen 路径保留原有历史尺寸和比例行为；
- 质量参数到 `imageSize` 的映射不变。

## 验证

- 适配器回归测试覆盖 `864x1152 -> 3:4`、既有尺寸映射、未知输入和 Imagen 旧映射；
- `git diff --check` 已通过；
- Go 格式化、编译和测试需由 GitHub Actions 执行，生产 VPS 不运行源码构建或测试。

## 回滚

若 CI 或生产 smoke check 失败，恢复上一份已验证的 GHCR 镜像；代码回滚仅涉及
Gemini 适配器及其测试，不需要数据库迁移或配置回滚。
